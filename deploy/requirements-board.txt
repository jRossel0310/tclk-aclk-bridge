# Board-side Python deps for the KR260 readout tooling (NOT the sim venv; the sim

# >= 5.1 for HEXPIRE (hash-field TTLs): the {TCLK}:watchdog field must expire ~1 s after
# the publisher stops refreshing it, which is how the deployment detects a dead producer.
# Needs redis-server >= 7.4 on the other end. An older client is reported in the
# publisher's last_error rather than silently publishing a watchdog that never expires.
redis>=5.1

# gps_calibrate.py and tclk_faithfulness.py import numpy at module level, and
# qa_report.py imports gps_calibrate for its timing section, so the one-command QA
# check needs this too. The publisher and the readers do not: if you only need to
# capture, redis alone is enough.
numpy
